This project is a C compiler LLVM frontend written in Rust.

## Always strictly follow
- Never run git commands that mutate the tree.
- Never Modify this file.
- Only read the C90 standard text if necessary (big file)

## Constraints
- Must strictly conform to ISO/IEC 9899:1990 (C90).
- Behaviors must be compared to gcc with -std=iso9899:1990 -pedantic-errors flags.
- Diagnosis do not need to strictly have the same wording.
- Target architecture is Intel386; must comply with the System V ABI.
- Zero external crates: pure std Rust.


## Build & test
- `make` — build cc1; regenerates src/parser/lex.rs and src/parser/yacc.rs from c.l/c.y.
- `make test` — compile test/hello.c.
- `make c` — cross-check against gcc -std=iso9899:1990 -pedantic-errors.

## Editing
- Refrain from editing the code, always prefer suggestion, I am doing most of the editing work.
- After any edition run the checklist bellow.

## Post editing Checklist
- run `cargo build` (or `make`)
- run `cargo fmt --check`

## Generated files (do NOT edit)
- src/parser/lex.rs  ← generated by ft_lex/ from src/parser/c.l
- src/parser/yacc.rs ← generated by ft_yacc/ from src/parser/c.y
- Only edit c.l / c.y instead, never manually edit src/parser/yacc.rs  and src/parser/lex.rs.
- ft_lex/ and ft_yacc/ are custom lex/yacc implementations; modify only as last resort.

## Layout
- src/ast       — AST definitions
- src/semantic  — semantic analysis
- src/parser    — lexer/parser (generated + grammar)
- src/arena     — arena allocation
- src/utils     — helpers
